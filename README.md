# FSD Studio 🎨

**Minecraft Skin Studio for Android** — by **FSD ETC** (Freedom • Success • Dream)

Search any Minecraft Java username (or upload your own skin file), make beautiful pose renders and AI artwork of your character, and download them for profile pictures, thumbnails and banners.

## Features (V1)

- **Skin search by username** — type a Minecraft name, get the real skin instantly
- **Skin upload** — use your own 64×64 skin PNG, with local preview renders (front / back / head / face)
- **18 pose renders** — wave, dab, dance, zombie, cheer and more (10 free, 8 Pro)
- **AI renders** — describe a scene in words, get AI artwork of your character (3 free per day)
- **Backgrounds & sizes** — transparent / dark / purple / white, up to HD (Pro)
- **Download & share** — save renders to your gallery (`Pictures/FSD Studio`) or share anywhere
- **History** — every render you make is kept in the app, ready to re-download
- **FSD Pro structure** — all poses, HD, 50 AI renders/day, no ads (purchases open at launch)

Default language: **English** (Hindi & Bangla language packs planned).

## How it works

- Player profiles & pose renders: [skinrender.dev](https://skinrender.dev) free API (keyless) + Mojang texture data
- AI images: [Pollinations](https://pollinations.ai) free tier
- Aggressive on-device caching: the same render is never requested twice — kind to the APIs, fast for you

## Tech

Kotlin · Jetpack Compose (Material 3) · Coil · Room · DataStore · GitHub Actions CI builds
